# Design Context
- **Audience**: single user (the owner) tracking their own life — personal, private, used daily, often quickly between tasks.
- **Use cases**: log each hour/slot of the day fast; capture build ideas; track what I'm doing / learning next; review a date range for insights.
- **Tone**: calm, focused, a well-kept field notebook / almanac. Warm paper, ink, editorial serif headings. Honest, not gamified.
